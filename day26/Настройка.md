
Установить Ollama
macOS: brew install ollama (или приложение с https://ollama.com/download)
Linux: curl -fsSL https://ollama.com/install.sh | sh

Скачать модель
$ ollama pull llama3.2:3b

Запустить
$ ollama run llama3.2:3b

API
curl http://localhost:11434
