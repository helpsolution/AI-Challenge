# Правила ревью репозитория AI Advent Challenge

Ревьюер получает этот файл целиком в каждом PR. Здесь общие правила репозитория; правила конкретного приложения — в README его папки.

## Устройство репозитория

- Каждая папка верхнего уровня `dayN` — отдельное приложение со своей сборкой Gradle. Код предыдущих дней переиспользуется копированием и доработкой, а не зависимостью между папками. Изменение в одном дне не должно ломать другой.
- Стек: Kotlin и Spring Boot (Gradle Kotlin DSL, JDK 21), фронтенд — Vue 3 из CDN, статику отдаёт тот же Spring Boot. LLM — DeepSeek по OpenAI-совместимому REST, локальные модели — Ollama.
- Задания учебные. Лишние зависимости, AI-фреймворки (Spring AI, LangChain4j) и защитные лимиты, без которых код работает корректно, не добавляются. Отсутствие тестов проблемой не считается: задания проверяются живым прогоном.

## Секреты

- API-ключи и токены живут только в `.env` (он в `.gitignore`) или в переменных окружения. Ключ не уходит на фронт, не попадает в репозиторий, в ответы API и в логи — даже на уровне debug.
- В журналах и трассировках заголовок с ключом заменяется на `***`.

## Слои Spring Boot

- Контроллер только разбирает HTTP и вызывает сервис. Бизнес-правила и проверки живут в сервисе, иначе их обходит любой другой вызывающий код.
- Настройки — через `@ConfigurationProperties` и `application.yml`, а не литералами в коде.
- Ошибку внешнего сервиса (LLM, Ollama, вебхук) не глотают молча: её либо показывают пользователю дословно, либо пишут в лог с причиной. Пустой `catch` и `catch (e: Exception)` без обработки — ошибка.

## Время и конкурентность

- Текущее время берётся из бина `Clock`, хранится и передаётся в UTC (`Instant`). `LocalDateTime.now()` и системный часовой пояс на сервере — ошибка.
- Проверка и запись общего состояния выполняются атомарно: если соседние методы сервиса защищены блокировкой, новый метод, меняющий то же состояние, тоже должен быть под ней.
