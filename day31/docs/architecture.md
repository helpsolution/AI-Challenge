# Архитектура ассистента дня 31

## Модули

`assistant` — приложение Spring Boot на порту 8311. Оно отдаёт Vue-интерфейс, принимает `/help`, ищет документацию через RAG, обращается к MCP-серверу и вызывает DeepSeek. Основная логика находится в `assistant/src/main/kotlin/advent/rag/agent/DeveloperAssistant.kt`.

`project-mcp` — локальный MCP-сервер на порту 8312, транспорт Streamable HTTP, endpoint `/mcp`. Три инструмента: `git_branch`, `git_status` и `list_files`. Корень репозитория задаётся `PROJECT_ROOT`, по умолчанию `..` относительно каталога `day31`. Реализация доступа к git: `project-mcp/src/main/kotlin/advent/project/mcp/ProjectRepository.kt`.

## Пайплайн /help

1. Проверить сообщение и определить проект. День в тексте вопроса важнее выбора в интерфейсе. Если указаны разные дни, попросить выбрать один.
2. Через MCP получить текущую ветку. По смыслу вопроса дополнительно вызвать `git_status` или `list_files`.
3. Для вопросов только о git-контексте или списке файлов показать результат MCP напрямую, без RAG и LLM.
4. Для вопросов о документации проверить SHA-256 содержимого и настроек индекса. При изменениях пересобрать индекс.
5. Получить эмбеддинг вопроса, отобрать до 20 кандидатов только выбранного дня, переранжировать BGE и взять до 5 фрагментов с оценкой не ниже 0.
6. Передать DeepSeek найденные фрагменты, результаты MCP и до 6 сообщений истории этого проекта.
7. Проверить JSON, ссылки и дословные цитаты. Если проверка отклонила ответ, дать модели одну попытку исправления по тем же источникам. Повторно неподтверждённый ответ не показывать как достоверный.
8. Вернуть ответ, источники, данные инструментов и трассировку.

Справка без вопроса: `/help`. Текущая ветка не сохраняется в RAG: она запрашивается заново через MCP. Если ветка недоступна, ассистент показывает предупреждение, а не придумывает её.

## Разделение данных

RAG хранит README и Markdown из папок docs. MCP получает актуальные факты из git и списка файлов. История используется только для понимания вопроса. Она не считается доказательством и не переносит номера источников между ответами.

Индекс хранится в `day31/data/index/knowledge.db`. История диалога сохраняется в localStorage браузера; кнопка «Новый диалог» её очищает. Сервер хранит только 100 последних трассировок в памяти. Перезапуск очищает журнал трассировок, но сохраняет индекс на диске.

## Ограничения

Ассистент отвечает по документации и именам файлов. Он не читает содержимое исходников через MCP и не вносит изменения в проект. Список файлов может быть сокращён, поэтому отсутствие пути в сокращённом списке не доказывает отсутствие файла в репозитории.

Проверка цитат подтверждает наличие выдержки в источнике. Правильность смыслового вывода требует проверки на контрольных вопросах.
