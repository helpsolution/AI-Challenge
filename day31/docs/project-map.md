# Карта репозитория AI Advent Challenge

## Структура

Каждый каталог `dayN/` — самостоятельное приложение отдельного дня челленджа. У каждого дня собственные Gradle wrapper, настройки, README и модули. Команды запускаются из каталога выбранного дня. Порты, модели и ограничения одного дня не относятся автоматически к остальным.

Стек приложений: Kotlin, Spring Boot, Gradle Kotlin DSL и JDK 21. Веб-интерфейсы используют Vue 3 и отдаются как статические файлы Spring Boot. Облачные обращения к DeepSeek выполняются сервером; ключ не передаётся браузеру.

## Примеры проектов

- `day19`: дайджест Хабра. Модули `habr-service`, `habr-mcp` и `bot`. MCP соединяет Telegram-агента с API поиска, сводки и сохранения отчётов.
- `day25`: RAG-чат с историей диалогов в SQLite и памятью задачи.
- `day28`: локальный RAG и сравнение генераторов. Поиск: `nomic-embed-text` в Ollama, косинусная близость, BGE-реранкер. Генерация: локальные `qwen3.5:9b`, `llama3.2:3b` и необязательный облачный DeepSeek.
- `day29`: лаборатория настройки локальной модели для разбора обращений покупателей в JSON. Модуль `lab`.
- `day30`: приватный AI-сервис с OpenAI-совместимым API, авторизацией, очередью, rate limit и контролем контекста. Модуль `llm-service`.
- `day31`: ассистент разработчика. Модули `assistant` и `project-mcp`.

Подробные инструкции и реальные ограничения находятся в README соответствующего дня. Документация описывает проект; наличие файла, состояние рабочего дерева и текущая ветка проверяются отдельно через MCP.
